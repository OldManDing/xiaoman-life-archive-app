## 本页结论

最影响还原度的是 CTA 变橙（#1）、卡片奶油实心无玻璃感（#2）、选中标签白字对比不足（#3）——三者叠加让整屏从「深琥珀强调 + 奶油玻璃」变成「同一橙色铺满」。改法：先删掉 CSS 末尾 6369 起的「实测取色」覆盖块，恢复 6124 的深棕 CTA 与 6351 的白玻璃卡，再把选中标签换回 #E9A05A 面 / #8A4E14 字，即可一次性回收 3 条 P0 与 2 条 P1。
