## 本页结论

最影响还原度的是品牌图形、行高体系与字号阶梯：Logo 仍是产品 app 图标而非设计中的单色年轮线稿，行高 56px 比设计 68px 紧 18%，字标 26px、页脚 10px 双双偏小。改法：换 SVG 线稿并去阴影 → `--ui-row-min: 68px` → 字标 34px / 页脚 13px，再把三卡并回两组，即可拉回八成观感。
