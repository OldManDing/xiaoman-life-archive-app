## 使用方式

1. 按页打开文档，从 P0 往下改；改完勾掉「改完自检」。
2. 每页改完重截一张 390×844@2x，与文档里的「左右对照」链接比对。
3. 全局项（G1–G10）改一次即可覆盖多页，不要逐页重复调色。
4. 新增问题请直接追加到对应页文档，保持每页 20 条的口径。
