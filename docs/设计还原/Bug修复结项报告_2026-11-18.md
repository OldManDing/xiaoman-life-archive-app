## 四、方法论

1. **先 dump 类名再写选择器**：`info-shell` / `account-shell` / `members-shell` 混用曾导致三轮 CSS 静默失效。
2. **优先级要打满**：既有样式用 `#root#root` + `:has()`，覆盖必须 `#root#root#root`；同权重后写者胜。
3. **内联样式压不过 `!important`**：JSX 改字号无效时先查是否有历史 `!important` 规则。
4. **实拍不可省**：编译通过 ≠ 用户看到正确（曾把模板字符串写坏，页面直接显示 `formatAppDate(...)` 源码）。
5. **改坏就回退**：16 屏头像改造引发 JSX 结构错误，直接 `git checkout` 后换「拦截默认行为」的轻量方案。
