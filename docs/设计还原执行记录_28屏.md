## 3. 尚未闭合

- **12 邀请家人结构差异**：设计为「微信邀请 + 复制链接/短信 + 邀请码 + 折叠二维码」，实现为「二维码 + 邀请码 + 分享链接」。属能力差异（无微信 SDK/短信模板），非样式问题。
- **16 孩子档案高度**：实测 `scrollH 917`（> 842），需轻微滚动；设计画布为 618dp 短屏，等比后内容超出可视高度。
