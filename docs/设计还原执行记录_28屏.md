### 方法论沉淀

1. **先 dump 类名再写选择器**：ccount-shell / rchive-shell / info-shell / settings-shell / legal-shell 各自页面不同，凭文件名猜必然失效。
2. **优先级是要打满的**：既有样式常用 #root#root + :has()，覆盖必须 #root#root#root；同权重时后写者胜，且幂等规则（如 .rd-body p）会反杀自己的子元素规则。
3. **内联样式压不过 !important**：搜索空态标题改 JSX 无效，因为早前某轮的 !important 规则仍在。
4. **截图不可省**：选择器命中≠视觉正确（27 屏文案截断、28 屏插图压字，全靠截图发现）。
5. **清单本身有误判**：11 设置「记录组三开关整体缺失」、12「重新发送入口缺失」、16「头像卡中卡/缺出生时间行」实测均已实现。
